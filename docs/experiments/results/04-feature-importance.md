# RF 特征重要性分析

## 文档目的

本文档记录 Causal RF 模型的特征重要性分析结果，以及基于这些发现的特征工程洞察。论文中的 Feature Analysis / Ablation Study 部分应直接引用此文件。

**分析方法**：
- 训练 Causal RF (w=100, n=100, depth=15) 于 2-fold LOSO
- 提取 `sklearn` 的 `feature_importances_`（基于 Gini impurity decrease）
- 平均跨 fold，按轴和统计类型分组

---

## 一、按传感器轴的重要性

### Table 1: Feature Importance by Sensor Axis

| 轴 | 重要性占比 | 传感器类型 | 关键洞察 |
|----|-----------|-----------|----------|
| **ax (X轴加速度)** | **25.5%** | ACC | **绝对主导！** rep 检测最关键信号 |
| **gz (Z轴陀螺仪)** | **16.5%** | GYRO | 手腕绕 Z 轴旋转（如 curls）的关键信息 |
| **ay (Y轴加速度)** | **15.8%** | ACC | 垂直方向加速度变化 |
| **az (Z轴加速度)** | **15.3%** | ACC | 前后方向加速度 |
| **gy (Y轴陀螺仪)** | **14.5%** | GYRO | 手腕俯仰旋转 |
| **gx (X轴陀螺仪)** | **7.6%** | GYRO | **最弱轴**，手腕左右旋转信息有限 |
| **mag (合成幅度)** | **4.8%** | Derived | **远低于单独轴**，各轴独立信息更有价值 |

**关键发现**：
- **ACC (ax+ay+az = 56.6%) vs GYRO (gx+gy+gz = 38.6%)**：加速度整体更重要，但陀螺仪贡献了 ~39%，不可忽视
- **mag 仅 4.8%**：合成幅度虽然直观，但**严重损失了各轴的独立信息**
- 这直接解释了为什么 Peak Detection（只用 mag）在 curls/crunch 上完全失败，而 ML 方法（利用 ax, gz 等）能稳定检测

## 二、按统计类型的重要性

### Table 2: Feature Importance by Statistic Type

| 统计量 | 重要性占比 | 说明 |
|--------|-----------|------|
| **mean** | **13.8%** | 窗口平均幅度 |
| **q75 (75th percentile)** | **12.0%** | 高位分布信息 |
| **max** | **11.8%** | 峰值强度 |
| **std** | **11.5%** | 波动幅度 |
| **median** | **10.7%** | 中心趋势 |
| **q25 (25th percentile)** | **10.7%** | 低位分布信息 |
| **min** | **9.9%** | 谷底强度 |
| **tv (total variation)** | **8.2%** | 累计变化量 |
| **argmax** | **6.1%** | 峰值位置（时间） |
| **argmin** | **5.4%** | 谷底位置（时间） |

**关键发现**：
- **分布统计量（mean, q25, q75, median）共占 46.2%**，说明 rep boundary 检测更依赖「整体分布形状」而非单一峰值
- **argmax/argmin 只占 ~11%**，说明「峰值位置」不是最关键信息
- **std (11.5%) 和 tv (8.2%)** 合计近 20%，说明「变化率/波动」信息非常重要

## 四、特征工程洞察

### 4.1 当前特征集的问题

| 问题 | 证据 | 影响 |
|------|------|------|
| **缺少 velocity/jerk** | 当前只有 raw ACC/GYRO 统计量 | 无法捕捉「运动变化率」，而 rep boundary 本质上是「运动状态变化」 |
| **缺少频域特征** | 无 FFT/频谱特征 | rep 具有周期性（~0.3-0.5 Hz），频域信息可能帮助区分 phase |
| **缺少交叉轴特征** | 无 ax×gy, ay×gz 等 | 不同轴之间的耦合关系未被利用 |
| **argmax/argmin 利用不足** | 仅占 11%，但 gy_argmax 排第 14 | 如果加入「相对位置」特征可能更有价值 |
| **时间上下文不足** | 1.0s window 已不错，但缺少「前后对比」 | rep boundary 是「突变点」，前后差异特征可能有价值 |

### 4.2 建议新增特征（按优先级）

**P0（高优先级）**：
1. **Velocity（一阶差分）**：`diff(x) / dt`，然后取统计量
2. **Jerk（二阶差分）**：`diff(diff(x)) / dt²`
3. **前后窗口对比（delta features）**：当前窗口与前一个窗口的统计量差异

**P1（中优先级）**：
4. **频域特征（FFT）**：主导频率、频谱能量
5. **交叉轴特征**：ax×gy, ay×gz 等
6. **ACF（自相关函数）**：窗口内的自相关峰值

**P2（低优先级）**：
7. **Phase-aware 特征**：距离上一个 concentric 开始的时间
8. **Action-specific 特征**：不同动作的关键特征子集
